# oop-team-project

## 1. 프로젝트 소개
본 프로젝트는 Java 객체지향 프로그래밍을 기반으로 영화관의 영화 및 상영 정보 조회, 좌석 예약, 요금 계산 기능을 구현하는 영화관 관리 시스템입니다. 

## 2. 주요 기능
### 영화 및 상영 정보 조회
- 영화 목록 조회
- 영화 상세 정보
- 극장 및 상영관 선택
- 날짜 및 상영 시간 선택
### 좌석 예약
- 관람 인원 선택
- 상영 회차별 좌석 배치 확인
- 좌석 선택 및 예약
- 이미 예약된 좌석의 중복 예약 방지
### 요금 계산
- 일반 및 청소년 등 인원 유형별 요금 계산
- 조조 등 시간대별 할인 적용
- 좌석 및 상영관 유형에 따른 요금 차등 적용
### 결제 및 예약 확인
- 최종 결제 금액 확인
- 가상 결제 처리
- 예약 내역 확인

## 7. GitHub 협업 방식
1. GitHub Issues를 활용하여 작업 내용 및 수정 사항 등록
2. 기능별 Branch 생성 후 각자 개발 진행
3. 작업 완료 후 Commit 및 Push
4. Pull Request 생성
5. 다른 팀원의 코드 리뷰 및 피드백 반영
6. 검토 완료 후 Main Branch에 Merge
7. 통합 테스트 및 오류 수정
